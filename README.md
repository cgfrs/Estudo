# Estudo — IFPA 2026 | Cargo 402

Repositório central do projeto **IFPA ESTUDOS** para o concurso **IFPA 2026 — Cargo 402: Analista de Tecnologia da Informação**, banca **Instituto AOCP**.

## Objetivo

Centralizar o método de estudo, ciclo de matérias, checkpoints, progresso, banco de erros, materiais e o **IFPA StudyOS**.

## Método atual

O projeto usa duas regras principais em conjunto:

1. **Modo Acelerado por Questões**  
   Diagnóstico → microteoria direcionada → questões → análise dos erros → revisão curta → próxima matéria do ciclo.

2. **Modo Fracionado**  
   Pequenos intervalos durante o trabalho são usados para questões, recuperação ativa, revisão e banco de erros. Blocos longos ficam para conteúdos novos/difíceis.

### Referência de distribuição
- 20–30% teoria
- 60–70% questões
- 10–20% revisão
- avanço por assunto em torno de 75–80% de acertos **com compreensão adequada**
- revisões D+1, D+7 e D+30

## Estrutura

- `docs/` — metodologia, regras e painel geral
- `disciplinas/` — estado e próximos passos de cada matéria
- `materiais/` — revisões e notas de alto rendimento
- `studyos/` — painel HTML do projeto
- `privacidade/` — regras para evitar versionamento de documentos pessoais
