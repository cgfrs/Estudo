# Privacidade do repositório

Mesmo sendo um repositório privado, **não versionar documentos pessoais desnecessários**.

## Excluir
- diploma digital original com identificadores pessoais;
- CPF, RG e datas de nascimento em documentos;
- certificados com números de validação pessoais;
- arquivos XML de documentos pessoais;
- credenciais, tokens, senhas ou chaves;
- capturas contendo dados privados sem necessidade acadêmica.

## Regra
O repositório deve armazenar o **conteúdo de estudo**, não documentos de identidade do estudante.
