# Ativos visuais

O projeto também possui imagens, PDFs e DOCX gerados durante os estudos e durante a criação do StudyOS.

Nesta sincronização, o conector do GitHub permite versionamento direto de **conteúdo textual**. Por isso, os conteúdos essenciais foram preservados em Markdown/HTML e os documentos pessoais foram deliberadamente excluídos.

Ativos binários podem ser adicionados posteriormente sem alterar a estrutura lógica do repositório.
